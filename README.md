# TransInput：独立输入法

状态：已实现Rust核心、Windows TSF、中文输入与可选DeepSeek翻译；当前已安装本机未签名验收版，正式发行尚未就绪。更新日期：2026-10-23（Asia/Shanghai）。最新检查与阻塞见 [Windows交付记录](docs/DELIVERY.md)。

已安装460×198逻辑像素紧凑候选框、28行高，保留逐行中文与选中行英文。本机74项及GitHub双架构检查通过；用户本轮复验确认“布局符合预期，未见明显闪烁”。本轮记录与范围见[截图修正报告](docs/testing/2026-10-23-compact-candidates.md)，此前旧版失败保留；此反馈不等于所有应用/长时验收或公开批准。

仓库 [jihongit/TransInput](https://github.com/jihongit/TransInput) 当前为**私有验收仓库**，须登录授权账号访问。只有用户验收并明确同意后才可公开，不发布公开安装包或分享链接。此前GitHub Windows x64/x86构建记录保留，但不代替系统安装、真实应用和长时验收。

TransInput 面向中文用户：本地完成中文输入，可选使用 DeepSeek 将当前选中的中文候选翻译成自然、准确的美式英语，在同一行显示并可提交英文。

本目录为独立项目，包含自写引擎、测试、文档和图标。用户于2026-10-23要求移除旧版，原Weasel/Rime 0.17.4.6及旧安装残留已卸载；微软拼音保留。DeepSeek配置已在本机迁移为新版DPAPI密文，旧个人数据有加密备份。**新版已按用户明确授权安装为本机未签名验收版**，两架构系统COM/TSF激活、停用/启用、卸载/重装通过，未设默认输入法；正式签名与真实应用验收仍有待完成。详见 [本机安装报告](docs/testing/2026-10-23-local-installation.md)。最新状态见 [迁移与清理记录](docs/testing/2026-10-23-private-migration.md)。

## 已确定的方向

| 项目 | 决定 |
| --- | --- |
| 项目名称 | TransInput |
| 项目归属 | 用户个人 GitHub 账号 [jihongit](https://github.com/jihongit)；[jihongit/TransInput](https://github.com/jihongit/TransInput) 暂为私有，验收并明确批准后才公开 |
| 产品范围 | Windows 首版；架构同时考虑 macOS、Android、iOS / iPadOS |
| 自研范围 | 输入引擎、平台接入、候选与翻译交互自主实现，不嵌入 Weasel、librime、Mozc、Fcitx 等现成输入法引擎 |
| 允许复用 | 官方平台 SDK、通用基础库与 UI 框架、授权明确的开源词库；逐项核对许可 |
| 共享核心 | Rust：拼音、候选排序、词库与用户学习、翻译规则和状态管理 |
| 平台接入与 UI | Windows 以 C++20 薄接入层和原生 UI 为基线；Apple 平台 Swift；Android Kotlin |
| 翻译 | DeepSeek 只做中文到英文，每次请求独立，默认自然美式英语 |
| 无模型时 | 中文输入正常；不提供离线翻译，不显示可提交的英文 / 双语条目 |
| 设置 | 简单配置：翻译开关、API Key、测试连接、保存；Windows 从托盘进入，不添加开始菜单快捷入口 |
| 开源目标 | 不允许把受许可约束的衍生版本闭源对外分发；新写代码使用 AGPL-3.0-only，第三方与品牌分别记录，发布前完成分发审查 |
| 品牌素材 | 采用用户提供的“中 A →”图标；已保存原始透明 PNG |

语言采用原因和边界见 [ADR-0001](docs/decisions/0001-language-and-platforms.md)。平台原型不满足要求时，通过新决策记录调整局部实现，不让业务核心绑定某个平台。

## 当前进度

- 已实现：Rust 工作区、65,125 条第三方基础词表、自研查询与组合、翻译调度 / C ABI、CLI；C++20 TSF、独立候选 / 翻译后台、有界异步管道与原生候选窗。TSF 已连接真实词库和行内英文、等待 / 重试及敏感输入类型过滤；另有托盘设置原型、系统 JSON / WinHTTP、当前用户 DPAPI 和原图标运行时适配。自编小词表仅用于单元测试。
- 已验证：x86 / x64 的 Rust 单元测试、严格编译与静态检查、C++ / Rust 跨语言调用、COM 生命周期、进程内真实 TSF 输入上下文；详见测试报告。
- 已接入基础简拼、按词频索引的补全和组合态中文标点；新增 40 项真实词表质量基线，实际回归结果见后续报告。真实 DeepSeek 九句固定样例全部成功，耗时 813～1266 ms，不代表所有原文或实际输入场景均已验收。
- 鼠标选词已接入并增加候选变化、只读和失焦校验；本地选词学习支持成功中文提交后的偏好排序、DPAPI 保存与重启恢复。纯动作与自建 TSF 宿主测试不代替桌面实际点击。
- 普通中文模式的 2–9 待选已改为有界条件选择；无效序号保留拼音，后续组合命令有序执行。数字、失焦、停用和写入失败恢复的检查结果见快速数字选词报告。
- 已接入最多 90 个候选的分页、第二页学习，以及长译文换行 / 滚动；离屏 DPI 图片已检查，不代表真实多屏和鼠标操作通过。
- 托盘设置已连接学习开关、清空与保存错误提示。最新双架构完整检查为72/72，每架构46 Rust单元+6词表集成，102个构建相关源码/数据文件和55个直接构建二进制/PNG记录快照。自有原生 RichEdit 测试入口已纳入回归，用户已在本机反馈基础输入/Caps混输/候选移动正常；词条内全简拼混写的代表性输入和取消也获“正常，无明显异常”反馈。仅在自身窗口接入，不代表其他应用或长时验收通过。
- 基础混输使用大写锁定（Caps Lock）：未提交中文先完成，再追加保留大小写的英文；后续数字和符号不越过尚未完成的上屏。用户实测“你好GPT测试”正常；英文不进入翻译或学习。小写英文自动识别及国际键盘等仍待扩展 / 验收。
- 设置新增“个人词库”：明确添加 / 删除词条和拼音，最多1024项，独立加密保存；完整拼音参与整句组合，已支持按分隔音节简拼、至少两字母前缀补全和最近成功选词的排序记忆。补全保留基础首屏，可能需翻页。清空偏好不删词，删除词不被旧记忆复活，保存失败不提前替换当前模型。词库不批量上传，开启翻译时仍可能发送当前候选中的个人词。
- 候选定位采用组合起点和布局通知的异步只读会话，起点滚出可见区域时回退至活动光标；只读锁延迟、通知合并和文字不重写已检查。真实多屏及其他应用中的可见效果仍待验收。
- 已支持词条内全拼/简拼混写，如 `srufa` → 输入法、`zhguo` → 中国；明确分隔音节的个人词同样适用。查询沿有界音节树匹配，直接完整词条与已有简拼保留首屏，合法混写词优先于偶然碎字组合。
- 已接入候选UI的宿主显示协商与UI Automation提供程序，含选择/提交/取消、名称/坐标/状态、旧对象失效、模块寿命和显示关闭事件。已嵌入自写黑白输入指示和版本资源，原彩色图标不变。组件测试不代表严格UILess、实际读屏或其他应用验收通过。
- 已生成带哈希/清单/许可的Windows开发预览ZIP，并准备独立白名单源码导出和发布脚本；未签名版本不能输出正式发行包，开发注册入口拒绝系统变更。详见交付报告。
- 尚未完成：任意混写片段整句、完整标点与混输扩展、正式输入质量与宿主隐私兼容验证；候选窗和托盘设置的完整桌面交互、DPI / 深浅色 / 无障碍仍待验收。当前排序按最近选择优先，并非纯频次算法。
- 源码已同步到私有验收仓库；未来对外开放另行取得用户批准。历史GitHub Windows x64/x86构建与控制台检查通过。尚未完成新版正式系统安装/升级/卸载、记事本/浏览器/Office真实输入验收、8小时资源测试、正式发行安装包和Apple/手机资源。

当前完成的是隔离原型验证，P1 的真实宿主验收仍未完成。桌面自动化运行环境报 Windows 登录权限错误 1385，已记录为阻塞项。不要把后台集成测试或可编译 DLL 当作已交付的日常输入法。后续按 [实施路线](docs/ROADMAP.md) 继续。
