# ADR-0004：当前账户可运行的 Windows 设置原型

日期：2026-10-21。状态：已实现与构建，通过离屏布局检查；真实桌面交互未验收。

Windows 设置原型采用独立 C++20 / Win32 程序和系统原生控件。当前只有翻译开关、API Key、测试连接与保存，尚不足以证明引入 WinUI 运行时的部署收益。公司电脑无管理员权限，本阶段优先使用已有系统能力，manifest 明确 `asInvoker`、`uiAccess=false`，不安装额外 UI 运行时。这是 ADR-0001 中设置“优先 WinUI 3，原型核对部署成本”后的局部实施选择，不改变 Rust 核心与各平台原生接入的语言方案。

- `TransInputSettings.exe` 默认打开设置，`--tray` 隐藏驻留托盘；点击托盘显示设置，右键只有设置 / 退出。未注册登录自启、服务或开始菜单快捷入口。
- 原始 PNG 随原型复制，运行时缩放为 HICON 用于窗口 / 托盘；原件不修改。没有引入 UI 框架、字体包或图标库。
- Key 用密码框显示，粘贴的前后空白被去除。保存与连接测试在工作线程执行，界面不等待网络。退出时只发取消信号，等待通过消息完成，不能在 UI 回调中 join。
- 显式“测试连接”发送固定虚构句子，不自动保存或启用配置；“保存”使用当前用户 DPAPI，并通知后台重新加载。没有读取 / 迁移旧版真实 Key。
- 自动翻译和显式连接测试共用当前登录会话的一个请求名额。正在处理其他请求时，连接测试显示稍后再试；命名 mutex 的原持有线程异常退出后可恢复，不留下永久消耗的 semaphore 名额。
- 默认禁用翻译；启用说明明确当前中文发送给 DeepSeek 及可能产生 API 费用。模型 / 地址等高级参数不暴露给用户。

`--render-preview <path>` 只渲染本程序自己的隐藏窗口，使用虚构 Key、不读取真实配置、不添加托盘或联网。它检查原生布局和品牌资源，不能代替托盘点击、键盘导航、读屏、深浅色及多屏 DPI 的真实验收。

当前是轻量原型。后续根据真实视觉 / 可访问性验收决定是否保留控件方案、改用 DirectWrite 绘制或引入 WinUI；调整以体验和维护成本为依据，不增加与需求无关的页面或设置。
