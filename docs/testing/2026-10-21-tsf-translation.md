## 测试隔离

`TransInputPrototypeTest.dll` 仅连接自建 `TransInputTranslationFixture.exe`，返回固定虚构译文；没有 HTTP 或 Key 能力。该 fixture 的控制指令只存在于测试进程，测试目标不通过注册表、环境变量或 DLL 导出覆盖。正式 `TransInputPrototype.dll` 没有 fixture 目标分支。

TSF 测试在自建 ITextStoreACP / ITfInputScope 中创建真实 SDK 上下文，profile 和类工厂仅测试进程可见，不注册系统输入法、不向记事本 / 浏览器注入按键，不改变默认输入法。模型译文质量不能由 fixture 的英文结果证明。

## 本轮修复

1. 即时重试完成时原先被候选回调忽略，导致已经返回成功但英文未显示。修复事件接收后通过英文 / 双语 / 重试回归。
2. 后台丢失上下文时，只发 retry 不能重建原文。显式 F5 改为携带当前候选的新 revision 观察；没有新增自动付费重试。
3. 连接后立即断开的探测可能让 Accept 返回失败，旧逻辑会退出处理线程。改为保留线程并接受下一连接，增加断开探测回归。
4. 补全 SDK 输入类型 GUID 定义，测试 DLL 独立导出名称；两架构编译通过。
5. 设置采用 DPI 尺寸布局，保存 / 测试异步，密码框不泄露文本；修正离屏预览输入框绘制与测试脚本参数拼接。失败构建 / 预览未计入最终通过。
