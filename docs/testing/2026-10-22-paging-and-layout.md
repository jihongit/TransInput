## 实现

- 自研词库查询扩展为最多 90 个候选，每页最多 9 项；原来的 40 条固定质量基线保持通过。句子切分的 beam 仍为 9，不进行无界枚举。
- `TiSnapshot` 仍为 ABI v1 的 5,712 字节。新增 `TiCandidatePage` / `ti_engine_page`，不扩大每次旧快照。新 `QueryPage=4` 一次只传一页和页号 / 总数，消息上限仍为 8 KiB；旧 Query 保留。
- PgUp / PgDn 或未按 Shift 的 `-` / `=` 翻页。数字、空格、鼠标作用于当前页；第一页 / 末页有界，编辑拼音返回第一页。候选未返回时的翻页和数字选择仍异步、有序。
- 当前页变更失效旧候选、鼠标按下与旧译文。翻译仍只发送该页当前高亮中文；第二页选中的中文能学习并在重启后提升到首页。
- 候选按实测文字高度换行；长内容受工作区高度限制，可通过滚轮和原生滚动条查看。编号在长行滚动时仍可见，点击和绘制使用相同像素布局。未完成新一帧绘制时拒绝按旧像素位置选词。
- 渲染测试只使用自有 DIB 和固定虚构文字，不捕获桌面，不读取用户文档、Key 或真实学习文件。正式 DLL 不暴露测试渲染接口；GDI+ 预览编码仅编入测试 DLL。
