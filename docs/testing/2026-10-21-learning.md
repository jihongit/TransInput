## 学习行为

- 每次明确选择中文且原始 TSF 上屏操作全部成功后才提交学习；在同一编辑会话中重新读取输入类型。预览、取消、只读、写入失败、未知 / 敏感输入、原拼音 Enter 和英文 / 双语选择不学习。
- 只保留该次拼音、选中中文、次数与最近顺序，最多 512 条。最近选择优先；不同拼音互不影响。只重排当前词典的候选，不允许导入数据插入任意文字。
- `transinput_learning.h` 使用有界句柄、调用方拥有的字节缓冲区与事务性导入。内存导出上限 512 KiB；512 条最大长度记录经过边界 / 往返测试。
- 学习队列与输入查询分开，最多 64 条，优先处理提交与候选。学习失败不能使已经上屏的文字失败、重放或等待。
- 候选后台主线程执行延迟 / 周期原子保存，查询线程不持文件锁。实际路径为 `%LOCALAPPDATA%\TransInputNext\learning.bin`，当前用户 DPAPI 加密与用户 DACL；没有学习云同步。
- 学习文件读取在查询线程开始接收请求后执行；加载期间可提供基础中文候选，加载完成后才应用偏好。加载前的学习记录会跳过，避免随后导入覆盖新记录；文字提交不受影响。
- 损坏 / 不支持版本的文件保留，不自动覆盖；内存排序继续工作。保存失败退为内存排序，稍后有界重试。保存状态的可见提示与清理入口仍待界面完善。

设置与学习复用 `shared/protected_file.h` 的系统 DPAPI / 原子替换，不新增加密算法、外部依赖或模型；设置格式与旧项目配置未迁移。共享存储重构后的虚构 Key、HTTP 故障与设置布局继续通过。

## DLL 重载身份修复

代码审查发现旧的 DLL 生命周期内递增会话号会在卸载后重置，而翻译后台仍可能保留该客户端的较高 revision。新组合可能被当作旧观察拒绝。现在每个输入 / 翻译组合使用系统 CNG 生成的非零 64 位随机标识，标识生成不在 DllMain 执行，不作为权限凭据。

正式 / 测试 DLL 每架构各 1000 次 COM 生命周期继续通过；测试 DLL 在实际 `FreeLibrary` 后重新加载，新的标识未重复先前测试值。正式 DLL 不暴露测试接口。随机标识避免固定计数器的确定性复用，不声称有限位数随机值在数学上绝不碰撞。
