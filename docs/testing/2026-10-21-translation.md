## 开发中发现和处理

1. 补充跨语言翻译 ABI 后，严格检查发现测试中的 unsafe 注释位置不符合 Clippy 规则；修正后两架构检查通过。
2. C++/WinRT 需要显式引入 Foundation / Collections 投影头；初次编译缺失，已补全并核对 MIT 许可。
3. 初次逐字节 fixture 使用 `Sleep(1)`，本机实际调度粒度使发送耗时超过测试预算。调整为小块分片，并将“正常分片”和“故意停顿超时”分别验证，没有因此放宽正式 3 秒预算。
4. 反复新建 WinHTTP 会话时，短测进程句柄回收不符合预算；改为长生命周期 actor 复用一个网络会话，每个请求仍独立。请求与父句柄均等待最终关闭通知，不提前释放回调内存。
5. 译文中的 NUL / 控制字符在核心和平台两层拒收，避免在 Windows 上屏时截断或出现不可见控制内容。
