# 已知问题

本文记录影响使用的已知限制。TransInput 目前为开发预览软件，自动构建与组件检查通过不代表所有应用均已兼容。

## 首段输入可能没有英文

新启动输入法时，如果翻译配置尚未读取完成就开始输入，中文候选可以正常显示，但本段可能一直没有英文。即使后台随后准备就绪，该段也不会自动补上翻译。

临时处理：按 Esc 取消这段组合，稍后重新输入。如果之后仍没有英文，检查托盘设置中的翻译开关、API Key 和连接状态。不要把所有无英文情况都归因于此问题。

配置晚到的场景已在 x64、x86 隔离 TSF 测试中复现；尚未修复。

## 候选与英文上屏可能闪烁

在部分应用中，输入期间候选可能短暂清空；选择英文后，可能看到候选关闭、短暂空白或文字显示延迟。Notepad++ 中已有实际反馈与录屏，问题尚未解决。

没有经过验证的通用临时修复方式。对显示效果敏感的文档，请先使用固定虚构文本测试所在应用；必要时切换至其他输入法继续工作。

## 更新后应用仍使用旧版

Windows 应用可能在进程中保留已加载的输入法模块。更新磁盘文件后，仅切换输入法、最小化窗口或关闭一个标签页，可能无法加载新版。

请保存文档并完全退出、重新打开对应应用。输入法不会强制结束用户程序。

## 平台与兼容性范围

- 当前提供 Windows 实现，没有可用的 macOS 或移动端版本。
- x64 / x86 组件检查与自有原生编辑器测试不能替代浏览器、Office、编辑器等真实应用验证。
- 多物理显示器、动态 DPI 切换、休眠唤醒、远程桌面及所有敏感输入控件尚未完成全面兼容验收。
- 没有正式签名发行包；本机未签名预览安装是单独选择的测试模式。

反馈问题时请提供版本、系统和应用版本、预期与实际结果，以及固定虚构文本的复现步骤。不要附带 API Key、真实文档或个人输入数据。
