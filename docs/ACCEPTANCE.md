# 验收要求

更新：2026-10-21。本文定义完整验收要求，实际执行子集见 [首轮报告](testing/2026-10-21-p1.md)；未列为已执行的场景继续待验收，不能从局部自动测试推定整体通过。

## 验收证据

每份报告至少记录系统版本、CPU / 内存、显示与缩放、宿主版本、架构、源码版本、词库哈希、输入模式、操作步骤、实际结果、时间 / 资源指标和异常证据。自动测试、后台接口测试与真实应用可见输入测试分别记录。

旧版的接口、压力或安装检查不继承为新实现的通过结果；编译通过、进程存活、HTTP 返回成功也不等于能在软件里正常打字。

## 功能与兼容矩阵

| 类别 | 必测场景 | 预期 |
| --- | --- | --- |
| 基本输入 | 单字、短语、整句、同音词、简拼、英文、数字、标点 | 组合和候选正确，可修正且可提交 |
| 连续编辑 | 快速输入、重复按键、退格、长按、光标中间编辑、选词、翻页、Esc | 不丢字、不重复、不残留错误组合 |
| 焦点与上下文 | 切换窗口、切标签、鼠标移动光标、切换输入法、原输入框销毁 | 不向错误窗口提交，不让旧候选 / 译文更新新组合 |
| 未配置模型 | 无 Key、关闭翻译、保存配置后新组合 | 中文正常，无可误触的英文 / 双语条目 |
| 翻译交互 | 等待中提交中文、切候选、英文 / 双语提交、关闭翻译、连续新组合 | 提交内容属于当前原文，未就绪不提交空或旧译文 |
| 网络故障 | 断网、超时、鉴权错误、限流、TLS 错误、连接闲置、异常 JSON / 超长响应 | 中文不中断，资源有界，错误不连环弹窗 |
| 进程故障 | 输入服务退出、翻译进程退出、IPC 半写、客户端断开、启动失败 | 按规格恢复组合；无主线程无界等待，无文字重放 |
| 系统生命周期 | 休眠恢复、锁屏 / 解锁、用户切换、宿主退出、卸载 / 重装 | 状态与对象安全回收，配置按规则保留 |
| Windows 宿主 | 记事本、浏览器常见表单、Word / Excel、Codex / Electron、终端、x86 与 x64 应用 | 真实键盘输入和可见候选分别完成验收 |
| 特殊权限 | AppContainer、不同完整性级别、UILess / 可测试游戏类输入、远程桌面 | 不扩大权限绕过系统；记录可用性范围和限制 |
| 显示与无障碍 | 100% / 125% / 150% / 200% 缩放、多屏、深浅色、字体缩放、读屏 | 清楚可读、不抢焦点、不异常遮挡或跳动 |
| 数据 | 自定义词、学习、损坏词库、配置迁移、并发读写、升级中断 | 可恢复，用户数据不无声丢失 |

“覆盖各种场景”按明确矩阵落实，不承诺所有软件或系统保护输入框都能使用。未通过场景进入已知问题，不能以语言或框架选择替代实测。

## 稳定性与资源

- 组合 / 候选状态机、编码和接口边界做有意义的单元测试与属性测试。
- Rust unsafe、FFI / JNI、COM 引用计数、回调解绑、DLL 卸载和取消回收单列集成测试。
- 逐步执行合成突发输入、真实宿主快速输入、服务故障与持续使用，不把故障注入直接施加到用户正在编辑的重要文档。
- 观察线程、句柄、任务、队列、内存、CPU 与缓存，不能出现持续无界增长。
- 初期短时场景稳定后，再执行长时运行；正式候选版本建议包含至少一轮 8 小时受控持续 / 空闲交替测试，时长及负载由 P1 环境预算冻结。
- 同时验证输入正确性；快速返回但丢字或提交错窗口不算通过。

## 性能测量

以下是待 P1 冻结的预算建议，没有任何当前测量值：

| 指标 | 初始目标与说明 |
| --- | --- |
| 热态按键到本地候选可见 | 指定设备、词库与宿主下，初始争取 P95 不高于 30 ms；记录 P50 / P95 / P99 及最大值 |
| 界面帧耗时 | 60 Hz / 120 Hz 分别按约 16.7 / 8.3 ms 帧预算观察掉帧，不用平均 FPS 掩盖停顿 |
| 冷启动与首次候选 | 单独测量，不能隐藏首次词库加载、字体加载和运行时启动开销 |
| 中文与翻译 | 分开计时；160 ms 稳定等待和 DeepSeek 网络耗时不算作本地候选算法耗时，也不能从完整端到端报告中删掉 |
| 资源 | 冻结目标设备后设内存 / CPU / 线程 / 句柄预算；有界且长时无泄漏趋势，不提前编造数字 |

达不到目标时先定位词库加载、队列、绘制、锁和调度，再决定优化；不能未做同条件测量就宣称 Rust / C++ 更快。

## 翻译质量与安全

- 使用固定虚构语料，覆盖中文口语意图、自然美式表达、正式 / 技术语气、数字、否定、条件、代码路径、换行和歧义。
- 原文含“忽略以上提示”等指令时仍只翻译；不执行工具或系统操作。
- 验证请求体仅包含固定提示词和本次原文；无历史消息、无周边文档、无用户词库上传。
- 每次请求独立与多个请求之间的缓存命中分别测试；缓存隔离和旧请求结果归属必须正确。
- 未配置 Key、没有权限、Key 错误时不进行离线回退；设置和诊断不泄露 Key、授权头或真实输入。
- 自动规则检查只能覆盖部分错误；代表性翻译需要人工核对，不能把少量样例通过写成准确率保证。

## 安装与发布

- 干净安装、覆盖升级、重复安装、取消升级、重启和卸载均有实际记录。
- Windows 不生成开始菜单快捷入口；托盘设置可达，系统应用管理可卸载。
- 签名 / 校验、文件来源、版本、词库许可、源代码获取方式、构建说明、已知问题与实际安装包一致。
- 安装包与仓库不包含 API Key、个人输入数据、签名私钥、缓存、诊断转储或无法再分发的文件。
- 用户在本机完成代表性日常使用反馈；开发方负责测试和修复，不把完整 QA 工作转交用户。

## 图标验收

检查应用大图标、Windows 16 / 20 / 24 / 32 px 托盘尺寸、macOS 菜单栏模板表现、Android 自适应图标安全区和 iOS 图标导出要求。检查浅色 / 深色背景及不同缩放下的可读性；原图透明度、圆角和边缘不能被错误处理成黑色方底。
